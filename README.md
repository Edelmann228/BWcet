## Описание 
**WCET PID Analyzer** — консольное приложение на Python для оценки временных характеристик одного шага ПИД-регулятора. 

Программа рассчитывает:
- Лучшее время выполнения `BCET` (Best-Case Execution Time)
- Худшее время выполнения `WCET` (Worst-Case Execution Time)
- Коэффициент недетерминизма `WCET / BCET`
- Вклад памяти в худшее время выполнения (штрафы за промахи кэша)
- Вклад ветвлений в худшее время выполнения (штрафы за ошибки предсказания переходов)
- Соблюдение заданного дедлайна аппаратной платформы.

---

## Основные возможности 
- Расчёт `BCET` и `WCET` для всего набора операций.
- Учёт архитектурных штрафов процессора (промах кэша, ошибка предсказания перехода).
- Расчёт коэффициента недетерминизма.
- Пооперационный вывод результатов в виде форматированной таблицы в консоли.
- Чтение параметров процессора и структуры операций из одного конфигурационного JSON-файла.
- Автоматический анализ выполнения условий жесткого реального времени (`WCET <= deadline`).

## Входные данные 
Программа ожидает на вход файл `pid_step.json` в корневой директории со следующей структурой:

```json
{
  "processor": {
    "base_cost": 2,
    "cache_miss_penalty": 12,
    "branch_misprediction_penalty": 6,
    "deadline": 100
  },
  "operations": [
    {
      "name": "Чтение уставки",
      "type": "чтение",
      "memory_accesses": 1,
      "branches": 0
    },
    {
      "name": "Ограничение сигнала",
      "type": "ветвление",
      "memory_accesses": 0,
      "branches": 2
    }
  ]
}
```

### Параметры процессора (`processor`):
- `base_cost` — базовая стоимость выполнения одной операции в тактах.
- `cache_miss_penalty` — штраф за одно обращение к памяти в случае промаха кэша (в тактах).
- `branch_misprediction_penalty` — штраф за ошибку предсказания перехода (в тактах).
- `deadline` — максимально допустимое время выполнения фрагмента кода.

### Параметры операции (`operations`):
- `name` — название операции.
- `type` — тип операции (например: арифметика, чтение, ветвление).
- `memory_accesses` — количество потенциальных обращений к памяти.
- `branches` — количество инструкций ветвления.

---

## Расчёты 

Лучшее время выполнения одной операции:
```text
BCET_op = base_cost
```

Худшее время выполнения одной операции:
```text
WCET_op = base_cost + (memory_accesses * cache_miss_penalty) + (branches * branch_misprediction_penalty)
```

Итоговые метрики:
- **BCET** = Σ `BCET_op`
- **WCET** = Σ `WCET_op`
- **Коэффициент недетерминизма** = `WCET / BCET`
- **Проверка дедлайна**: `WCET <= deadline`

## Как запустить 

### Требования
- Установленный Python версии 3.7 или выше (код использует `dataclasses`).

### Подготовка файла данных
Убедитесь, что в папке с кодом находится корректный файл `pid_step.json`.

### Запуск анализатора
Запустите скрипт через терминал:
```bash
python main.py
```
